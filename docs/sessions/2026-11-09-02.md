## Source (checked 2026-11-09)

G. Elmas, I. A. Litvin, P. Kohl and J. Nötzel, "Modeling and analysis of phase instability in a photonic processor",
Applied Optics 64(14), 3995 (2025), doi:10.1364/AO.560370.

- Verification: the Crossref record for the DOI (title, authors, volume, issue, page and date all match). The
  accepted manuscript, arXiv:2606.25196v1, was read in full.
- sigma = 0.25 [sec]^-1/2 (Sec. 4 text and Fig. 3 caption). The authors set this Brownian-model value so that the
  simulation matches 35 measured runs of 300 s each. The phase distributions differ by about 9%.
- sigma = 0.15 [sec]^-1/2 (Sec. 6 text and Fig. 6 caption). The authors matched this value to one feedback-control
  run.
- Label: peer-reviewed. Each value is the authors' fitted model parameter, not a statistic they report directly.
- Limit: the paper measures relative phase between two input fibers, driven by cooling-fan airflow. That is not
  drift of programmed mesh weights, which is what E-023 drifts. E-039 therefore uses the rate as a stated proxy, and
  every interval it produces is an estimate under that proxy.
