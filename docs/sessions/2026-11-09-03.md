Source labels:

- Budgets: measured by us (stored E-023 result, #219, L1).
- sigma: peer-reviewed. These are the elmas2025 authors' model values matched to their measurements of
  **input-fiber relative phase**, so they are a stated proxy for programmed-weight drift, not a weight-drift
  measurement.
- k: estimate (first-order bound formula).
- Intervals: estimate (formula) under the proxy.

The intervals are bounded by E-023's coarse budget grid: the true tolerable budget lies between the stored value and
the next grid value. None of this is a device prediction, a measured recalibration time, or a speed or energy claim.
The stored `inputs.assumptions.path` is an absolute build-box path, because the registered module records the path
it resolved. A run from another checkout path would differ only in that string.
